# CXR Tuberculosis 2021 Yaushev

Web version of the CXR Tuberculosis 2021 quiz, for iPhone, iPad and desktop browsers.

- **Test**: works like the original Windows program. You get 42 random questions (6 per section) and 20 minutes, and see your result at the end.
- **Practice**: the same 42 random questions, with no time limit and a "Correct Answer" button.

## Using it offline on iPhone / iPad

1. Open the GitHub Pages address of this repository in **Safari**, with internet on.
2. Tap **Share → Add to Home Screen**.
3. Open it once from the Home Screen icon while still online. The app and all 99 images are then saved on the device.

After that it works without internet.
